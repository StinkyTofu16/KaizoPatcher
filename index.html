Continue playing

You only need the steps below to change games or patches.

1Your game

Pick an unpatched .gba, .gb, .gbc or .nds file from Files. US versions only.

2Patch

Choose a game first. Patches that fit it will show here.

3Patch and save

  1. Tap Save to Files, then Download. The game lands in the Downloads folder of the Files app.
  2. In Delta, tap +, choose Files, and pick the game.
  3. DS games need your DS BIOS files added in Delta's settings first (Settings → Core Settings → melonDS).

4Randomize

Finish step 3 first. To randomize without patching, pick No patch in step 2.

Play in browser keeps this game and preset on your phone. Every New run re-randomizes it and starts a fresh save.

Each tap of Randomize makes a new, different game. The spoiler log lists every change.

The first run downloads a Java runtime (about 20 MB) and can take a minute. DS games are large and may be too much for some phones.
